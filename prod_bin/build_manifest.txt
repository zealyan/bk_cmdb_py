与 SOP 的差异 / 必须的补丁
----------------------------------------------------------------
1. UI: 除 SOP 要求的 @babel/runtime 外，package.json 还漏列
   terser-webpack-plugin / webpack-cli（webpack 5 已将其拆分为
   独立包）。需额外安装，否则 builder/webpack/optimization.js
   报 "Cannot find module 'terser-webpack-plugin'"。
   -> npm install terser-webpack-plugin@^5 webpack-cli@^4 --legacy-peer-deps
2. UI: @babel/runtime 安装须加 --legacy-peer-deps，否则与
   eslint-config-tencent 的 peer 冲突导致 npm install 失败。
3. UI: 本项目即 webpack 5，BUILD_OUTPUT 仅从 process.argv 读取、
   不读环境变量；未传参时输出到默认路径
   src/bin/enterprise/cmdb/web（与 SOP 第 5 节描述一致）。
4. 后端: 仅构建 SOP 列出的 6 个最小服务（非全量 11+ 服务），
   以加速并保证可用性；GOPROXY 使用 https://goproxy.cn 加速。
