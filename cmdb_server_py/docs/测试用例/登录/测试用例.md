## LOGIN-001 管理员登录成功

| 字段 | 值 |
|------|-----|
| **用例ID** | LOGIN-001 |
| **标题** | 管理员登录成功 |
| **优先级** | P0 |
| **前置条件** | 后端服务运行于 8080 端口，前端服务运行于 9093 端口 |

### 测试步骤

1. 访问 `http://127.0.0.1:9093`
2. 输入用户名：`admin`
3. 输入密码：`admin`
4. 点击「登录」按钮

### 预期结果

- [ ] 登录成功
- [ ] 跳转到首页 `/#/index`
- [ ] 无错误提示
